04 /

Filtrado y diferencias

GAUSSIANO · MEDIANA · RESIDUO

El filtro gaussiano suaviza variaciones; la mediana reduce impulsos. El residuo es la diferencia absoluta entre original y suavizada (amplificada ×4 para su visualización), no una medida exclusiva de ruido ni una prueba de edición.

05 /

Análisis de recompresión JPEG · ELA

JPEG CALIDAD 90

ELA compara la imagen con una versión recomprimida en JPEG. El contraste se amplifica para visualizar diferencias; estas pueden originarse en textura, bordes, formato previo o procesamiento legítimo. No demuestra manipulación.

Este ajuste solo modifica el contraste mostrado; no cambia el error calculado.
